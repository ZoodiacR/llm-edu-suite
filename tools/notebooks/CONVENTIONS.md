# How the notebooks are written

Every notebook in `notebooks/` is generated by one file in this folder (`nbXX_<slug>.py`). Edit the generator, then:

```bash
python tools/build_notebooks.py 10        # rebuild notebook 10 (no outputs)
python tools/run_notebooks.py 10          # execute it in place, keeping outputs
```

## What a notebook must be

1. **A lesson, not a demo.** Explain the idea first (what problem it solves, how it works, the intuition or formula), then the code, then what the output means. Write for a motivated engineer who has not used the tool yet.
2. **Use the tools the industry uses.** The application notebooks (07–16) use Hugging Face (`transformers`, `peft`, `trl`, `datasets`, `optimum-quanto`), LangChain, LangGraph, LangSmith, RAGAS and the official MCP SDK, through their current, non-deprecated APIs. When a short "how it works under the hood" cell makes the framework less magical, keep it short and clearly labelled.
3. **Measured, honest results.** Every notebook ends with an **Evaluation** section using the metric a practitioner would report, plus plots where they help. Prose about results must match the outputs of the executed notebook. If a technique does not help in our small setup, say so and explain why; never claim a number you did not see.
4. **Reproducible.** Temperature 0 for LLM calls, fixed seeds, small eval sets (10–30 items) so a notebook runs in minutes. Each notebook should finish in under ~10 minutes on a laptop GPU (RTX 3060, 6 GB).
5. **Comments read like a person wrote them.** Plain sentences that explain *why*. No `# =====` banners, no telegraphic arrow chains.
6. **Each notebook ends with Takeaways and a "Next:" pointer.**

## The setup cell

Application notebooks start with:

```python
nb.code(setup_apps("llm-edu-suite-10-rag"))   # from _common.py: repo-root finder, numpy/matplotlib, .env, LangSmith project
```

which ends by calling `llm_edu_suite.config.setup(project=...)`. Get models only through the config module:

```python
from llm_edu_suite.config import get_llm, get_embeddings
llm = get_llm()                     # ChatOllama(qwen2.5:3b, temperature=0) by default
emb = get_embeddings()              # OllamaEmbeddings(nomic-embed-text) by default
```

so that a reader can switch the whole course to another provider by editing `.env`.

## Local models and hardware

- Chat: `qwen2.5:3b` through Ollama (supports tool calling and structured output). Embeddings: `nomic-embed-text`.
- Hugging Face models for training: small enough for a 6 GB GPU (e.g. `HuggingFaceTB/SmolLM2-135M-Instruct`, `SmolLM2-360M-Instruct`). Always fall back to CPU when CUDA is not available.
- LangSmith tracing is on when `.env` has `LANGSMITH_TRACING=true` and a key. Notebooks must still run without a key.
